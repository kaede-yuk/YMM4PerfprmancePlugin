# YMM4 Performance Plugin

YMM4のドッキング可能なツールとして、CPU、RAM、GPUの使用率を1秒間隔で表示します。GPUはWindowsの`GPU Engine`パフォーマンスカウンターから各エンジンの使用率を取得し、最も高いエンジンを表示します。

## Display modes

- `バー`: CPU、GPU、RAMの順に使用率を太いバーで表示します。
- `波`: 使用率を低・中・高の文字と、文字の中で動く波で表示します。34%未満は緑、34%から67%未満は黄、67%以上は赤です。波の高さも実際の使用率に連動します。

GPUカウンターがWindows側で利用できない場合も、CPUとRAMは表示されます。GPU欄には利用不可と表示されます。

## 設定

YMM4の設定画面にある「ツール」カテゴリの「パフォーマンスモニター」から、使用率の文字表示、バー内の文字表示、フォント、波モードの文字にも選択フォントを適用するか、外側の余白、CPU・GPU・RAMの間隔を調整できます。フォント一覧は各フォントの見た目を確認しながら選べます。外側の余白と項目間隔は従来より広い範囲で調整できます。バー内の文字は左側に固定され、バーの高さに合わせてサイズが変わります。波モードはパネル幅に合わせて3列・2列・1列に切り替わり、項目の見出しと使用率表示を短くして狭い幅での見切れを抑えます。波モードでは、使用率の文字表示を無効にしても低・中・高の波表示は維持されます。
